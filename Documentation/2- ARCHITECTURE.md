# Architecture

## Overview

Percentage Calculator Tool Desktop v2.0.0 is a **Tauri v2 + Rust** desktop application.

It replaces the v1.1 Electron runtime while keeping the original HTML/CSS interface and exact calculation behavior intact.

```text
+---------------------------------------------------------------+
| Webview UI (ui/index.html, ui/styles.css, ui/main.js)         |
|  - terminal-inspired layout                                   |
|  - input parsing (parseFloat) & stale-reply sequence guards   |
|  - live formula & result DOM updates                          |
+-------------------------------+-------------------------------+
                                |
                                | window.__TAURI__.core.invoke(...)
                                v
+---------------------------------------------------------------+
| Tauri Shell & Commands (src-tauri/src/main.rs, commands.rs)   |
|  - window creation (1120x860, min 760x620, #0E0F12)           |
|  - calc_change / calc_percent_of_total / calc_portion /       |
|    calc_discount / calc_original                              |
|  - copy_text, get_app_info, show_about_dialog                 |
|  - --smoke-test mode & 20s watchdog                           |
+---------------+-------------------------------+---------------+
                |                               |
                v                               v
+-------------------------------+ +-----------------------------+
| Pure Rust Math Crate          | | Tauri Plugins               |
| (crates/percent-core)         | | - clipboard-manager         |
| - js_round & format_decimal   | | - dialog (native About box) |
| - 5 percentage calculators    | +-----------------------------+
| - unit + 10k golden tests     |
+-------------------------------+
```

---

## Main Architectural Parts

### 1. Pure Rust Calculation Layer (`crates/percent-core`)

All five calculators and decimal formatting live in:

```text
crates/percent-core/src/lib.rs
```

It has **no Tauri or OS dependency**, only `serde`. That keeps the math fast to compile and testable anywhere with `cargo test -p percent-core`.

To guarantee zero behavioral drift from the v1.1 JavaScript version, `percent-core` implements:

- `js_round`: matches ECMAScript `Math.round` (ties `.5` round toward `+∞`, e.g. `-2.5 -> -2.0`).
- `js_to_fixed_2`: matches `Number.prototype.toFixed(2)` (ties in the third decimal place round away from zero).
- `tests/golden_parity.rs`: verifies all five calculators and `format_decimal` against **10,661 golden test cases** generated by running the original v1.1 `src/calculations.js` in Node.

---

### 2. Tauri Desktop Shell (`src-tauri/`)

The desktop shell lives in:

```text
src-tauri/src/main.rs
src-tauri/src/commands.rs
src-tauri/tauri.conf.json
src-tauri/capabilities/default.json
```

It is responsible for:

- creating the native window (1120×860, min 760×620, background `#0E0F12`)
- serving the static frontend from `../ui`
- exposing typed `#[tauri::command]` handlers for the five calculators, clipboard writes, app metadata, and the About dialog
- enforcing a strict Content Security Policy (`default-src 'self'; style-src 'self'; script-src 'self'`) and least-privilege capabilities (`core:default`, `clipboard-manager:allow-write-text`)
- running the automated `--smoke-test` when passed on the command line

---

### 3. Webview Interface (`ui/`)

The frontend lives in:

```text
ui/index.html
ui/styles.css
ui/main.js
```

It remains plain HTML, CSS, and JavaScript with **no bundler and no npm dependencies**:

- `index.html` and `styles.css` preserve the v1.1 layout, element IDs, and terminal color palette.
- `main.js` parses input strings with the same `parseFloat` logic as v1.1, calls the Rust commands via `invoke(...)`, and uses a per-section sequence counter so out-of-order async replies can never overwrite newer input.

---

### 4. Test Layer

The project uses three levels of automated verification:

1. **Unit tests** (`crates/percent-core/src/lib.rs`) — direct ports of the original Vitest cases plus JS rounding edge cases.
2. **Golden parity test** (`crates/percent-core/tests/golden_parity.rs`) — 10,661 cases recorded from the v1.1 JS engine (`crates/percent-core/tests/fixtures/golden.json`).
3. **Real-window smoke test** (`percentage-calculator-tool --smoke-test`) — boots the actual Tauri app in hidden mode, drives the DOM inside the webview across all 30+ v1.1 checks (focus, live calculations, divide-by-zero errors, copy feedback, Clear All, version `2.0.0`, and real system clipboard write/read), and exits `0` or `1`.

---

### 5. Packaging & CI Layer

Packaging is configured in `src-tauri/tauri.conf.json` and `.github/workflows/build.yml`.

On every push and pull request, GitHub Actions runs:

1. `cargo fmt --check`, `cargo clippy`, and `cargo test -p percent-core` on Linux.
2. `cargo clippy --workspace`, `cargo tauri build`, and `percentage-calculator-tool.exe --smoke-test` on `windows-latest`.
3. Uploads clean Windows deliverables (`dist/Installer/` with NSIS `.exe` and `.msi`, plus `dist/Portable/Percentage Calculator Tool Portable 2.0.0.exe`).
